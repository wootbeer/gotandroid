God of Thunder (1993) Android
=====================

This is a source port of the original DOS game “God of Thunder” for Android.

You will need the game files from a licensed copy in order to play it.

Thankfully the license is free.
You can use any version of the game files, from any source. Shareware or
freeware all work the same and unlock the full game. But if you want a 
sure-fire working copy with a license for free, then you can get the game 
on Steam here: 
https://store.steampowered.com/app/738470/God_Of_Thunder/

Game Files
-------
Place GOTRES.DAT onto your device. 
Place in an accessible folder.
Any version of the file should work.

SHA1 hash of GOTRES.DAT:
344982E1956FDC3FE4BC269B16498EB5ACB08B95

On first launch the game will ask you to select the folder with the file.
If it closes you are not using the correct version of the file.

Installing / Updating
-------
Grab the latest APK from the [Releases](https://github.com/wootbeer/gotandroid/releases) page
and install it directly, or track it with [Obtainium](https://github.com/ImranR98/Obtainium) for
automatic update checks -- add it there with this repo's URL:
`https://github.com/wootbeer/gotandroid`

Controls
-------
Auto show/hide on-screen touch controls.
Optimized for handhelds.
The few controls can be remapped in-game.

Android Handhelds / Retroid Devices:
Make sure controller style is set to Retro or whatever your devices default is.
Ntndo style as opposed to Xbox style, swipe down menu to access these options.
