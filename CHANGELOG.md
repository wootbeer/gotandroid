## [0.1 (9-18-2026)]

### Added
God of Thunder, but with features on Android
- Gamepad support
- Basic touch support
- Content file selector
- Gamepad rebinding
- Various menu navigation
- Force 4:3 mode, use to force a 4:3 scale adding black bars
- If you are using a 4:3 device already like a Nova you don't need to enable this
- Minimal HUD display mode, minimal stretching due to this on widescreen
- Sound/Music level controls
- Cheat menu: god mode, all items in all episodes, etc
- Enhancement menu: hammer / armor colors, attack speeds, etc
- Can enable cut content hourglass item to play around with
- Mirror mode
- And much more

### Changed
- Original game's title screen, intro, and menu do not come with assets or source
- Recreated in this port
- Kept as true to DOS original as possible
- Gameplay quirks and bugs that may influence puzzles kept
- Minor mostly unnoticeable things fixed up


### Fixed
- Various quality of life and bug fixes
- Can no longer hit loki while vanished
